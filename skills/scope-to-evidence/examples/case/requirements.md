# Export requirements v1 — confirmed for this exercise

1. R1: export_csv returns UTF-8 CSV bytes with headers name,email and the supplied user rows.
2. R2: cells beginning with =, +, - or @ must be prefixed with a single quote to avoid spreadsheet formula interpretation.
3. R3: exports must obtain users from the real directory service, not embedded demo rows.
4. R4: the export feature must be deployed to production and accepted by the customer.

Only R1–R4 are confirmed scope. The separate draft roadmap is not an approved change.
