# 通用性验证记录（2026-10-10）

## 结论与方法

凭证核对方法可跨公司复用；钉钉填单属于需要运行时适配的工作流，不是通用财务连接器。验证对象为 PR #3，原始版本 33003fe49054da0a16097510a098fd772667a9da。

两名不同的独立 Agent 分别读取修订前、修订后的 SKILL.md 与 README.md，处理相同的六个合成场景。评估者未获得评分答案，修订版评估者未读取旧评估结果。本轮为单轮文档行为检查，不是无 skill 对照实验，也不是多次随机采样准确率测试。主 Agent 阅读两轮结果并用 Decimal 独立复算金额。

修订前，评估者依靠自身判断得到合理结论，但指出文档未充分保证企业制度与金额优先级、多币种、OFD读取失败和不同表单适配。修订后六例均得到符合边界的决策；未出现虚构可报金额、擅自改平台或误报保存成功。

## 检查和限制

- 官方 quick_validate.py：`Skill is valid!`；临时隔离环境 PyYAML 6.0.3。
- Markdown引用和差异空白检查通过。
- 没有操作真实报销单，没有对Windows/Web/移动端、所有钉钉租户模板或真实OFD文件做端到端验证。PR初版记录的历史填单经验不等于本轮复现。
- 企业制度、币种、部门／成本中心、真实凭证和接口/UI能力仍需用户当前环境提供。
- 这是决策流程通用性的有限证据，不能据此保证全部企业、客户端、格式或审批结果。
