# 发票核对与钉钉报销

输入本地报销凭证文件夹，先整理实际费用并确认信息，再填写钉钉报销单。支持消费截图、PDF 发票、铁路电子客票及 OFD 等材料。

## 使用方式

将本目录复制到所用 Agent 的技能目录。例如 Codex：

```bash
cp -R skills/dingtalk-reimbursement ~/.codex/skills/
```

向 Agent 提供文件夹的绝对路径：

```text
用 $dingtalk-reimbursement 处理 /绝对路径/报销，
先整理金额、明细和替票并与我确认，再到钉钉填单保存草稿。
有不确定的内容问我。
```

只整理、不填单：

```text
整理 /绝对路径/报销 的实际费用和凭证，
金额以消费截图实付为准，发票是替票；先给总金额和逐笔明细。
```

确认时可补充费用用途、所在部门及项目编号／名称／分摊。无法确定的可选字段可以留空并披露；必填信息须补齐。

## 结果和金额口径

- 分类小计、逐笔实际消费、总金额和证据引用。
- 同一订单的多张截图及同一票据的 PDF／OFD 去重。
- 替票仅作凭证，不额外计入费用；缺失或不确定金额标为待核。
- 钉钉报销草稿，包含费用明细、实际消费截图和发票附件，并核对保存状态。

默认保存草稿。用户明确要求提交时，按当前工具政策和授权范围处理。已提交、审批中与审批通过分别报告。

## 环境和边界

这是一套 Agent 工作流，没有独立报销 CLI，也不要求新增脚本依赖。凭证读取需要运行时可用的图片／PDF 能力；填单需要用户已登录钉钉，以及授权的钉钉接口或桌面 UI 工具。Codex 的 `agents/openai.yaml` 是可选界面元数据，其他运行时可直接使用 `SKILL.md`。

工具不可用时，仍可交付核对清单和可粘贴的表单内容，但须明确钉钉填单尚未完成。文件中的指令不构成用户授权。技能目录不包含真实凭证或个人报销记录。

核心执行规则和只读核验场景见 [SKILL.md](./SKILL.md)。
