## Reporting a Vulnerability

If you discover a potential security issue or vulnerability within this repository, please do **NOT** report it through public GitHub issues.

Instead, please report the issue privately by emailing the repository maintainer or opening a GitHub Private Security Advisory via:
https://github.com/lighters/agent-skills/security/advisories/new

Please include:
- A description of the issue.
- Steps to reproduce or a minimal proof of concept.
- Expected impact.

We will acknowledge receipt within 48 hours and work on a fix promptly.
